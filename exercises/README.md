# Coding exercises

Your personal files for each coding exercise come on Canvas: the brief (PDF), your template (`.qmd`) and your own data file, all with your name and matriculation number in the file name.

1. Save all three files into this folder.
2. Open your template in Positron, fill in the code cells and answers, and render it (Preview, Ctrl/Cmd + Shift + K).
3. Submit your `.qmd` and the rendered `.html` on Canvas.

Your data differ from everyone else's, so use your own files only. Pulling updates from GitHub never touches your files in this folder.
